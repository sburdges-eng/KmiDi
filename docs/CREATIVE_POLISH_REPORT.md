# KmiDi creative polish report

## Overall result

**READY**

## What now feels stronger

- **Intent:** The mood area leads. "Set the mood" in the centre of the wheel invites you to choose the emotional frame before anything else. The length warning is a single, calm line—"Shorten the arrangement to continue"—so it feels like a constraint of the room, not an error message.
- **Listening hierarchy:** The first thing you’re asked to do in the song-details panel—"Describe your song"—is slightly emphasised so the flow is: set the mood, then direction, then the rest. The screen supports that order.
- **Mix and timeline:** More space between Transport, Mixer, Timeline, and Master so each surface has its own place. The timeline readout uses "Duration" and a simple "Bars · Duration" line so it reads like a timing reference, not a spec sheet. The master level shows "Master" and the value; the strip stays clear and trustworthy.
- **Empty and waiting:** Lyric Spark says "Waiting for a spark." instead of instructions. Spectocloud says "Generate a piece first, then return here to visualize it." Lyric panel messages are shorter and human: "No lyrics yet", "Can't reach the server. Check the connection." These moments feel like pauses in a session, not system messages.
- **Conversation:** The inspiration log opens with "What do you want to make?" so the session starts as a question, not a status line.

## What was refined

- Mood centre copy: "Select" → "Set the mood".
- Length modal: one short line, no "Song length exceeded" tone.
- GhostWriter empty state: "Waiting for a spark."
- Timeline: "Estimated cycle: X s" → "Duration: Xs" and a cleaner "Bars · Duration" line.
- VU: label simplified to "Master" with active/idle kept for accessibility.
- Spectocloud and LyricPanel: shorter, calmer copy for empty and error states.
- App: first log line → "What do you want to make?"
- Layout: more space in the main grid and in the song-details panel so the first question ("Describe your song") has slightly more weight; timeline meta uses tabular figures and a touch of letter-spacing for a clearer readout.

## What still feels unresolved

- None that block use. The instrument is coherent and ready for long sessions. Optional later: the Inspire view could use panel titles that feel even more like parts of a single writing room (e.g. more musical, less "Mood Picker" / "Activity Feed") if you want to push the metaphor further.

## Final note

KmiDi now reads as a single room: you set the mood, then the direction of the piece, then the arrangement and instruments. The mix and timeline have clearer separation and read like a real workspace. When something is empty or when the server isn’t there, the copy stays short and human so the flow isn’t broken. It feels like a place to write and shape music—calm, exact, and ready for real work.
