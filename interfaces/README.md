# Interfaces

Phase 0 scaffolding for cross-project integration.

These interfaces provide stable integration points for legacy/imported systems:

- `IIntentEnricher`
- `IHarmonyEngine`
- `IGrooveEngine`
- `IArrangementEngine`
- `IMLAssistService`
- `IVoiceLayer`
- `IBiometricInput`

Behavior remains unchanged until concrete adapters are wired through the existing contract gates.
