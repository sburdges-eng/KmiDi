## Purpose

This directory contains all active source code for the KmiDi project. All files here are actively maintained and used in the build system.

## Directory Structure

- `core/` - Core library and Intent IR system
- `plugin/` - VST3/CLAP audio plugin source files
- `gui/` - Desktop GUI application files
- `bridge/` - FFI bridge for language bindings
- `stubs/` - Stub implementations for testing
