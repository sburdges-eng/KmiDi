# Datasets (pointer only — data not in repo)

Dataset files are local-only and are not committed to this repository.

- Place local datasets under `datasets/` on your machine as needed.
- Configure runtime data roots via environment variables (for example, `KELLY_AUDIO_DATA_ROOT` or `AUDIO_DATA_ROOT`).
- Keep large dataset contents out of git.

This directory exists as a deterministic, path-stable pointer for local development.
