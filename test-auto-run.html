🚀 UI Test Runner

Follow these steps to run automated UI tests:

Step 1: Make sure the dev server is running at http://localhost:1420
Step 2: Open the app in a new tab and press F12 to open DevTools
Step 3: Go to the Console tab
Step 4: Copy the script below and paste it into the console, then press Enter
Step 5: Type runUITests() and press Enter to start tests

console.warn(`⏭️ SKIP: ${name} - ${reason}`); } async function sleep(ms) { return new Promise(resolve => setTimeout(resolve, ms)); } async function clickButton(selector, description) { try { let btn = document.querySelector(selector);
